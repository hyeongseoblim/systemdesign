# 실제 기기·지하철 학습 점검

운영 주소: https://jobstudy-eta.vercel.app. 평소 사용하는 휴대폰과 브라우저로, 이동 중 안전한 때에 확인한다. 브라우저 데이터를 삭제하지 않는다.

1. 연결이 되는 곳에서 홈을 열고 추천 카드 한 장을 시작한다. 글과 도표를 읽고 질문에 짧은 답을 입력한다. 저장 안내가 표시되는지 확인한다.
2. 본문이나 도표 중간에서 홈으로 돌아간 뒤 이어보기를 눌러 읽던 위치로 돌아오는지 확인한다. 앱을 잠시 떠났다가 돌아와 답변도 남아 있는지 확인한다.
3. 이해도를 기록하고 완료한 뒤 홈에서 다음 카드가 보이는지, 복습 목록에서 기록한 카드를 다시 열 수 있는지 확인한다.
4. 지하철에서 연결이 약해지거나 끊겼다가 돌아올 때 화면이 멈추는지, 재시도로 회복되는지, 이미 쓴 답변이 유지되는지 확인한다. 방문하지 않은 카드나 모든 콘텐츠가 오프라인에서 열릴 것이라고 가정하지 않는다.
5. 작은 화면에서 버튼이 손가락으로 누르기 편한지, 글과 도표가 읽히는지, 키보드가 입력란이나 다음 버튼을 가리는지 확인한다.

결과는 날짜, 기기·OS·브라우저, 통신 상태(정상/약함/끊김), 각 단계의 성공 또는 문제, 문제가 난 화면과 재현 순서를 기록한다. 실제로 겪지 않은 끊김 상황은 미확인으로 남긴다. 답변 내용이나 개인 정보는 공유하지 않아도 된다.
